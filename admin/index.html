输入后台密钥

密钥就是云函数 admin 的环境变量 ADMIN_KEY 的值。 输入一次之后会记在这台电脑的浏览器里。

名称 营业时间 东北角 西南角 排序 状态 操作

区域在数据库里只存两个对角点：东北角和西南角。另外两个角是算出来的，不用填。 修改坐标后，小程序重新打开就能看到绿框移动。

示例数据：一键生成几个带不同评价数量和推荐度的夜市，用来预览小程序上的各种显示状态。 生成的区域和评分都带标记，可以随时整批清掉，不会碰你自己录的数据。
